# Trusted Further Learning Resources

These verified resources are for learner follow-up. They are separate from the factual grounding used to generate the lesson.

## Retrieval augmented generation (RAG) and indexes

- Source: Microsoft Learn
- Concepts: RAG overview, retrieve-augment-generate flow, indexes, retrieval methods, grounding, and citations
- URL: https://learn.microsoft.com/en-us/azure/foundry/concepts/retrieval-augmented-generation
- Description: Learn how external information is retrieved, added to a prompt, and used to produce grounded answers.
- Level: Beginner

## What is Retrieval-Augmented Generation (RAG)?

- Source: Google Cloud
- Concepts: RAG overview, fresh information, factual grounding, embeddings, vector search, and retrieval quality
- URL: https://cloud.google.com/use-cases/retrieval-augmented-generation
- Description: Explore why RAG is useful and how search connects external knowledge with a language model.
- Level: Beginner

## Retrieval Augmented Generation

- Source: Amazon Web Services documentation
- Concepts: external data, embeddings, similarity retrieval, augmented prompts, and model training limitations
- URL: https://docs.aws.amazon.com/sagemaker/latest/dg/jumpstart-foundation-models-customize-rag.html

## Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

- Source: Lewis et al., original RAG research paper on arXiv
- Concepts: original RAG architecture, parametric and non-parametric memory, neural retrieval, and research results
